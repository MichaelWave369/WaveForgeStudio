# WaveForgeStudio Architecture

WaveForgeStudio = WaveTalk × PHIAudio × WaveRider

- WaveTalk: governed signal, SGL policy, SML lineage/memory.
- PHIAudio: deterministic audio plan graph and stem topology (stub adapter in v0.1).
- WaveRider: deterministic visual world graph and scene/shot plan (stub adapter in v0.1).

The compiler emits synchronized packet artifacts, not rendered media.
