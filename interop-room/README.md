# WaveForge Interop Room

This directory is the static GitHub Pages surface for the WaveForge Interop Room.

It receives bounded ParaCut RenderPlan handoffs, verifies freshness and lineage, records an intake receipt, and can create a non-rendered release reference. It does not grant render, publish, network, subprocess, acquisition, or automatic-import authority.

Deployment is handled by `.github/workflows/interop-room-pages.yml` using GitHub Pages via GitHub Actions.
